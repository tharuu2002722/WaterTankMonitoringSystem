# Water Tank Monitoring System

## Project Overview
This project aims to design and implement an IoT-based water tank monitoring system to automate the process of monitoring water levels, controlling water pumps, and ensuring water quality. The system will help reduce water wastage, save energy, and prevent maintenance issues.

## Project Objectives
- Automatically monitor water levels and control pumps.
- Detect water quality using TDS and turbidity sensors.
- Send alerts to users through a mobile app (Blynk).
- Provide real-time monitoring through the mobile app.

## Requirements
- **Hardware**: ESP32, Ultrasonic Sensor (HC-SR04), TDS Sensor, Turbidity Sensor, Water Flow Sensor
- **Software**: Arduino IDE, Blynk App, GitHub

## Mobile App Interface
Use the Blynk mobile app to monitor and control the water tank system remotely.
